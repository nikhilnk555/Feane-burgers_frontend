# 🍔 Fast Food Restaurant – Frontend

A modern and responsive **Fast Food Restaurant frontend website** built using **HTML, CSS, and Bootstrap**. This project is designed to provide an attractive and user-friendly online experience for customers to explore the restaurant, view food items, read customer reviews, and get restaurant information.

## 🚀 Features

* 🍔 Attractive fast-food restaurant homepage
* 📱 Fully responsive design for mobile, tablet, and desktop
* 🍕 Food/menu section with attractive food cards
* ⭐ Customer review/testimonial carousel
* 🖼️ Restaurant and food image sections
* 📞 Contact and restaurant information
* 🎨 Modern UI with Bootstrap components
* ⚡ Smooth and simple navigation
* 📋 Clean and organized HTML & CSS structure

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **Bootstrap 5** – Layout, carousel, and responsive components
* **JavaScript** – Interactive functionality

The goal of this project is to create a visually appealing and responsive frontend for a fast-food restaurant. It focuses on practicing **frontend development, responsive layouts, Bootstrap components, and user-friendly UI design**.
